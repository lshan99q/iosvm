# S22 ext13 — launchd 栈采样（p_comm 猜测再次未命中）

**结论：ext13 到 UI（`end=qemu-exited ui=870s`），但 `ustacks=launchd`
0 次命中（303 条 `no process called launchd`）→ p_comm 不是 `launchd`。**

## 事实

- 本镜像的 launchd 是 `/sbin/launchd.darwin`（rc.launchd 的
  `exec /sbin/launchd.darwin`），其 `p_comm` 很可能是 **`launchd.darwin`**
  （16-byte 截断内）；
- widget 实际 spawn：`RemindersWidgetExtension [48]`、`FindMyWidgetItems [49]`、
  `BatteriesWidget [50]`；
- `ustacks=launchd` 全部 `no process` → 名字不对。

## 配方

- root `/tmp/root-w15.apfs`（`785bcbac`）；system `8bf5f838`；内核 `1f8c489f`；
- `XCMD="glwire_local=1 launchd_disable_all_timeouts=1 ustacks=launchd
  ustacks_at=650 ustacks_count=300 ustacks_ms=1000 ustacks_threads=8 ustacks_tname=*"`；
- `boot-measure.sh ext13 /tmp/root-w15.apfs 1100 --no-panel`。

## 判断

- 本发仍是**工具未命中**（p_comm 名猜错），不是「launchd 不存在」。
- 下一次直接 `ustacks=launchd.darwin`（或先用 `touch.py stacks launchd.darwin`
  验证名字）；确认后再看 elided 子进程的线程栈。
