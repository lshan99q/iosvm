## 判断

- **不是「全部都会 checkin」**：570s 内只有 2 个（ext24 的 4 个含不同请求集）；
- **Weather/Calendar 槽仍白块** → 内容没出来；
- 慢/卡的分界仍需按 code 的分支：有 spawn 无 exec → 需求/顺序；有 exec 几分钟无
  checkin → exec 后卡点；有 spawn 且 38s 内 checkin → 只是慢。
- `srmap` 只有 pid1 是预期（子进程继承 shared region），不是扩展看不到 cache 的证据。
