# S22 ext5 — ustacks 目标名不匹配（no process）+ CheckIn 0

**结论：ext5 跑完（`end=ui ui=750s ui_bytes=311213 guestframes=56
hostframes=1351`），但 `ustacks` 120 次全部报 `no process called
FindMyWidgetPeo` —— 实际 widget 进程名是内核截断的 **`PeopleWidget_iO`**
（`(pid/49 [PeopleWidget_iO])`），不是 `FindMyWidgetPeo`。`checked in as alive`
仍 **0**。**

## 判断

- **采样目标名错了**（`FindMyWidgetPeo` vs 实际 `PeopleWidget_iO`），本发没有拿到
  任何 live 栈；不是 H2/H3 的证据。
- `checked in as alive` 仍 0，与 ext4 一致：extension 能 spawn/INIT，但 CheckIn 不发。
- 本发不计入 H2/H3；预算已按 ext1–ext5 用完。

## 建议

- 若再给 1 发：`ustacks=PeopleWidget_iO ustacks_at=850`（判据同 code 的 H2/H3
  分类）；或 `ustacks_tname=*` 不指定进程做对比。
- 或直接接受「ext4/ext5 均无有效栈」的现状，转源码级 trace。
